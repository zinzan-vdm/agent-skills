# TAGS Format

The TAGS file is a flat list of tags used in its directory. One tag per line. No bullets. No YAML.

## Example

```
auth
cursor
database
pagination
```

## Rules

- Add a tag only when the tag is new.
- Do not remove tags. Stale tags are harmless. They just return no results on search.

## File location

`docs/patterns/TAGS` in the patterns directory.
