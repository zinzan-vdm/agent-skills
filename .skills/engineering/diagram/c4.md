# C4 Diagrams

C4 describes architecture at four levels: context, container, component, and code. Mermaid supports context and container well. The component level and the code level use class diagrams.

## Context

The context level shows the system and its users.

```
C4Context
    title System Context for Banking
    Person(customer, "Customer", "A bank customer")
    System(bank, "Banking System", "Core banking services")
    System_Ext(post, "Postal Service", "Sends mail")
    Rel(customer, bank, "Uses", "HTTPS")
    Rel(bank, post, "Sends statements", "Mail")
```

## Container

The container level shows one system from the inside.

```
C4Container
    title Containers
    Person(customer, "Customer")
    Container(web, "Web App", "React", "Frontend")
    Container(api, "API", "Node.js", "Business logic")
    ContainerDb(db, "Database", "PostgreSQL")
    Rel(customer, web, "Uses", "HTTPS")
    Rel(web, api, "Calls", "JSON")
    Rel(api, db, "Reads and writes", "SQL")
```

## Elements

| Code | Element |
|---|---|
| `Person` | a user |
| `Person_Ext` | an outside user |
| `System` | your system |
| `System_Ext` | an outside system |
| `SystemDb` | a database system |
| `Container` | an app, a service, or a store |
| `ContainerDb` | a database container |
| `Rel(from, to, label, tech)` | a relation |

## Warning

GitHub does not render C4 diagrams. Use mermaid.live or the Mermaid CLI to check the output before you send it.

## Rules

1. Use the context level for the big picture. Use the container level for one system's internals.
2. Keep one level per diagram.
3. Put a label on every relation.
